# cnn_for_drug_discovery
We build a convolutional neural network for Ligand-based Virtual Screening. Molecules are represented as isometric projections rendered from multiple viewpoints on a sphere.

Run the model by running the config file with desired settings and then running all cells in order in the jupyter notebook model file.

The program requires a path to a folder which contains two folder: one of decoys and one of ligands. The molecule files are often formatted differently so adjust parameters in the config file to match.
